Разработай комманду laravel которая будет парсить страницы типа https://www.mirturizma46.ru/beliy-lebed-anapa/

Входные данные:
- Название курорта
- Направление
- url страницы

Как парсить страницу:

- Находим тег h1 транслитерируем его как slug и создаем директорию по шаблону database/seeders/hotels/<Название курорта>/<транслитерированный h1>
- В блоке с классом slick-list находим все элементы a извлекаем у них href и скачиваем их в созданную ранее директорию в подкаталог img.  При этом в момент скачивания транслитеритуем имена файлов и собираем их в отдельный массив.

- Берем текст из элемента с классом baseDescr и анализируем его по следующему алгоритму: находим тег h3  и следующий за ним текст эти данные добавляем в массив формата:

```php
[
    'title': <текст из h3>,
    'description': <текст следующий за ним>
]
```

Получившийся массив добавляем в результирующий массив.

- Находим элемент script внутри элемента #to_import_number в нем json массив преобразуем его в массив php 
- находим элемент #to_import_before_5_price и запоминаем его содержимое 
- находим элемент #to_import_before_12_price и запоминаем его содержимое 

## Результирующий массив 

Собираем результатф парсинга в единыф массив и сохраняем его в файл rez.php в созданную директорию по шаблону database/seeders/hotels/<Название курорта>/<транслитерированный h1> именем массива пусть будет транслитерированный h1.
