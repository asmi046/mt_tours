# Создание калькулятора для расчета цены тура на море

Калькулятор должен быть реализован на Vue 3 с учетом следующих требований:

- использовать script setup
- использовать современные подходы, минимальный но читаемый код
- стили не реализовывай стилизация будет вне компонента.
- Имя компонента MainCalc.vue расположить компонент нужно в папке resources/js/components/Sea

## Входные данные

При помощи props в комопнент передаются:

- Список с типами номеров
- Список рейсов

## Данные запрашиваемые у пользователя

Данные переданные пропсами выводятся в виде выпадающего списка и пользователю при взаимодействии предоставляется возможность выбрать нужные параметы.

Так же у пользователя необходимо запросить следующие данные:

- Количество взрослых - (input number, по умолчанию 2)
- Количество детей до 5 лет - (input number, по умолчанию 0)
- Количество детей до 12 лет - (input number, по умолчанию 0)

## Что необходимо реализовать

Реализуй графический интерфейс опираясь на верстку которая реализована в компоненте resources/js/components/Sea/AleanCalc.vue

Реализуй пропсы и сбор данных с элементов интерфейса. Сделай метод который будет отрабатывать при изменении входных данных (сделай пустой метод логику реализуем пзже).

# Расчет стоимости проезда на море

В комопненте resources/js/components/Sea/WayCalc.vue реализуй следующий функционал:

- Добавь в шаблон компонет для выбра вида проезда. Будет 2 вида проезда: Туда и обратно, В одну сторону, по умолчанию выбран пункт Туда и обратно
- Добавь в шаблон компонет для выбора рейса по аналогии с имеющимся
- Добавь в шаблон блок для вывода цены за проезд
- Добавь в шаблон кнопку с текстом - Перейти к оплате. Кнопку не стилизуй просто присвой ей класс button.

## Алгоритм работы

В параметр передан массив из моделей SeaWayPrice, после инициализации компонента переменной let city присваивается первый города. При выборе города вызывается метод citySelect в нем выполняются следующие действия:

- В отдельную переменную загружается расписание по связи модели оно выводится в компонет для выбора рейса.
- обнуляется переменная отвечающая за выбранный рейс
- Проверяем есть ли у модели цена за одну сторону или только в две стороны. Если есть есть цена только за обе стороны и нет цены за одну в компонете выбора вида проезда отключается пункт - В одну сторону

При выборе рейса в отдельном поле отображается цена и становится активной кнопка перейти к оплате.

# Компонент добавления детей и их возроста

Нужно реализовать Vue компонет который будет состоять из следующих элементов:

- кнопка с текстом - Добавить
- Блок для выводов полей ввода возраста

Компонент должен работать следующим образом:
При нажатии на кнопку должен добавляться элемент input (number) с минимальным значением 1 и максимальным 18. На выходе элемент должен выдавать список вида 1, 2, 12 который заполняетс возростом введенным в добавленные поля. Компонент будет использоваться с директивой v-model.

Данный компонент подключи в файле resources/js/components/Sea/AleanCalc.vue в пустой div <div class="line"></div>.
