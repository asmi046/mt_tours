# Создание базы данных для раздела

Необходимо создать модели с миграциями и сидерами согласно списка ниже. Для каждого поля необходимо сделать модификатор comment().

Сидер должен работать на базе DB а не моделей. 

## Таблица - Рейсы

- Связь с таблицей Направления
- Заголовок
- Порядок вывода (по умолчания 0)

## Таблица - Направления

**Поля:**

- Заголовок
- Slug
- Регион
- Описание (nullable)
- Порядок вывода (по умолчания 0)

## Таблица - Цены

**Поля:**
- Связь с таблицей Направления
- Заголовок
- Порядок вывода (по умолчания 0)

## Таблица - Курорты

**Поля:**

- Связь с таблицей Направления
- Заголовок
- Подзаголовок (nullable)
- Slug
- Порядок вывода (по умолчания 0)
- Описание (nullable)

## Таблица - Отели

**Поля:**
- Связь с таблицей Направления
- Связь с таблицей Курорт
- Заголовок
- Slug
- Порядок вывода (по умолчания 0)
- Описание (nullable)
- Краткое описание (nullable)
- Галерея (json nullable)
- Параметры (json nullable)
