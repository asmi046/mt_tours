# Создание базы данных для раздела

Необходимо создать модели с миграциями и сидерами согласно списка ниже. Для каждого поля необходимо сделать модификатор comment().

Сидер должен работать на базе DB а не моделей. 

## Таблица - Рейсы

- Связь с таблицей Направления
- Заголовок
- Порядок вывода (по умолчания 0)

## Таблица - Направления

**Поля:**

- Заголовок
- Slug
- Регион
- Описание (nullable)
- Порядок вывода (по умолчания 0)

## Таблица - Цены

**Поля:**
- Связь с таблицей Направления
- Заголовок
- Порядок вывода (по умолчания 0)

## Таблица - Курорты

**Поля:**

- Связь с таблицей Направления
- Заголовок
- Подзаголовок (nullable)
- Slug
- Порядок вывода (по умолчания 0)
- Описание (nullable)

## Таблица - Отели

**Поля:**
- Связь с таблицей Направления
- Связь с таблицей Курорт
- Заголовок
- Slug
- Порядок вывода (по умолчания 0)
- Описание (nullable)
- Краткое описание (nullable)
- Галерея (json nullable)
- Параметры (json nullable)

tourName * Название тура. (тур у нас, это, например “Крым”, “Анапа”..)
tourCID * Уникальный код тура

14

checkInDate * Дата и время заезда в отель по правилам отеля
checkOutDate * Дата и время выезда из отеля по правилам отеля
hotelId * Идентификатор отеля.
hotelCID * Уникальный код отеля
hotelUrl Ссылка на страницу с описанием отеля.
resortId * Идентификатор курорта, в котором расположен отель.
hotelCategoryId Идентификатор категории отеля.
mealId * Идентификатор вида питания.
mealCode * Код вида питания.
htPlaceName * Упрощенное название размещения в номере (примеры:

DBL, TRP, 2 ADL + 1 CHD, 2 ADL + INF).

roomTypeName * Название типа номера (примеры: «Стандартный», «Люкс»).
tourDate * Дата начала тура в формате dd.MM.yyyy (пример:

31.12.2012).

nights * Если поиск без авиабилетов (только проживание), то
это - количество ночей в туре или санаторных дней
(если вам нужны именно ночи, то используйте для
вычисления значения поля checkInDate и checkOutDate)
.
Если поиск с авиабилетами, то это количество ночей
между датой вылета из города вылета и датой прилета
назад в город вылета

price * Цена тура в валюте, которая была указана во входном

параметре currencyId.

hotelPrice* Цена размещения в отеле (если тур без перелета, hotelPrice

= price)

hotelIsInStop * Наличие мест в отеле, допустимы значения: 0 – есть места,

1 – нет мест, 2 – запрос.

ticketsIncluded * Включена ли стоимость билетов в стоимость тура,

допустимы значения: 0 – не включена (тур только отель), 1 –
включена (пакетный тур).

fewPlacesInHotel Поле заполняется, если есть указание на то, что мест в

fewTicketsRtnY Поле заполняется, если есть указание на то, что мест

fewTicketsDptB Поле заполняется, если есть указание на то, что мест
бизнес класса туда мало. Если нельзя указать точное кол-во
оставшихся мест, то заполняется значением -1, иначе
указывается точное кол-во оставшихся мест.
fewTicketsRtnB Поле заполняется, если есть указание на то, что мест
бизнес класса обратно мало. Если нельзя указать точное
кол-во оставшихся мест, то заполняется значением -1,
иначе указывается точное кол-во оставшихся мест.
flags Набор битовых флагов тура. Тур может иметь несколько
установленных флагов одновременно, данное значение
является их суммой.
Возможные флаги тура:
1 – туроператор рекомендует данный тур;
2 – доступно мгновенное подтверждение;
4 – туроператор считает данный тур лучшим предложением;
8 – тур раннего бронирования;

16

16 – тур позднего бронирования;
32 – туроператор предоставляет скидку на данный тур;
64 – VIP предложение;
128 – тур доступен в кредит;
256 – тур является эксклюзивным предложением
туроператора;
512 – при покупке тура туристу подарок;
1024 – тур является комбинированным;
2048 – тур с обязательством (шоп - тур);

description Дополнительная информация по туру, например, для
комбинированных туров может содержать информацию о
проживании в отелях.

finder Строка с параметрами, используется, как входной параметр

line Внутренний ID-шник тура (часть, касающаяся наземного

перелетам (см. ниже п. 3.12), также используется, как
входной параметр для метода GetUrls

tline Внутренний ID-шник тура (часть, касающаяся перевозки),
используется, как входной параметр для метода GetUrls
trline Внутренний ID-шник тура (часть, касающаяся трансфера),
используется, как входной параметр для метода GetUrls

medical 1 - есть услуги лечения, 0 - нет услуг лечения
