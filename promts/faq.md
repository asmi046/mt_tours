# Добавление FAQ

Создай модель а к ней миграцию, контроллер и сидер для реализации раздела FAQ. Поля в модели следующие:

- Раздел - строковое обязательное
- Порядок сортировки - по умолчанию 0 числовойе
- Вопрос - строковое оябязательное длинна 500 символов
- Ответ - текстовое поле не обязательное

После создай компонент для отображения этого раздела. Логика работы следующая:

- в компонент переводится строка с именем раздела
- Отбираются записи из таблицы с этим разделом в выбранном порядке
- Пердаются для отображения во вюху

Во вюхе обертка в которой выведи данные в следующем формате:

```php
        <details>
            <summary>

            </summary>
            <div class="response">

            </div>
        </details>
```

Стилизовать не нужно элементы уже стилизованы.
