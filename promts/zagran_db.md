# Создание базы данных для раздела зарубежные туры

Необходимо создать модели с миграциями и сидерами согласно списка ниже. Для каждого поля необходимо сделать модификатор comment().

Сидер должен работать на базе DB а не моделей.

## Таблица - Зграничные направления

- Название курорта (строка, обязательное поле) - назвать title
- Изображение (строка, nulable, длинна 600) - назвать img
- Порядок вывода (цисло, по умолчанию 0) - назвать order
- Слаг для ссылки (строка, обязательное поле) - назвать slug
- Города вылета (строка, nulable)
- Перечень курортов (строка, nulable)
- Минимальное количество дней (строка, nulable)
- Минимальная цена (вещественный, обязательное поле)
- Скрипт для вывода поиска (текст, nulable)
- Скрипт для вывода горячих туров (текст, nulable)
- Текстовое описание раздела (текст, nulable)

## Таблица - Зграничные курорты

- Скрипт для вывода горячих туров (текст, nulable)
